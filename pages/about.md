# About this blog
{: #post-title }

这里记录我在系统、安全与 AI Infrastructure 领域的学习和研究。把读论文、看源码、做实验时的理解留下来，也给未来的自己留一份可以检索的 long context。

希望千年后，这些记录可以成为考古学家了解当代博士生活的一扇窗口。

**PhD = Prolonged Hard Days → (but) Progress Happens Daily.**
